# LuxCrypt-QKD-Simulator
LuxCrypt is a hardware-software bridge simulating Quantum Key Distribution (BB84 protocol). Using Arduino-controlled optics and a Python backend, it demonstrates secure key exchange and eavesdropper detection. A functional look into the future of cybersecurity.
